## 🌟 Highlights

- **🪟 Liquid Glass Studio UI:** Dark frosted acrylic panels with live hover previews, responsive drawers, and top pill controls.
- **🎵 Zero-Setup Media Sync:** Syncs automatically with Spotify, Apple Music, YouTube Music, browsers, and other players via Windows System Media Transport Controls (SMTC).
- **💫 10 Kinetic Lyric Styles:** Switch between 3D drifting typography, fisheye warps, starfield constellations, and live-typing terminals.
- **🌈 Ambient Screen Lighting:** Audio-reactive lighting and dual-blob backdrops that shift with your active track and album palette.
- **🖱️ Click-Through Overlays:** Lock or unlock floating lyrics to click through to windows underneath while working, browsing, or gaming.
- **⚡ Portable Executable:** Run the standalone release directly without installing extra runtimes.

## 🚀 Getting Started

### Requirements
- **OS:** Windows 10 or Windows 11 (64-bit)
- **Compatible Players:** Spotify, Apple Music, YouTube Music, Tidal, Chrome, Edge, Brave, VLC, and other SMTC-enabled media apps

### Quick Run
1. Open the [Releases](https://github.com/YOUR_USERNAME/SoulsLights/releases/latest) page.
2. Download **`SoulsLights.exe`**.
3. Run `SoulsLights.exe` and start playing music on your PC.

> [!TIP]
> Toggle **`🔒 Unlock / Lock`** in the top bar or hero banner to switch click-through mode when interacting with apps behind the overlay.
